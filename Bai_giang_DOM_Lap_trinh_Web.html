1. DOM là gì?

DOM (Document Object Model) là mô hình đối tượng tài liệu – một cách biểu diễn cấu trúc HTML/XML dưới dạng cây đối tượng (tree) mà JavaScript có thể đọc và thay đổi.

Khi trình duyệt tải một trang web, nó sẽ phân tích HTML và tạo ra một cây DOM. Mỗi thẻ HTML trở thành một node (nút) trong cây này.

Hình dung đơn giản:
HTML = bản thiết kế nhà
DOM = ngôi nhà thật sự đã xây xong, bạn có thể đi vào sửa cửa, sơn tường, thêm phòng…

Cấu trúc cây DOM cơ bản

document
 └── html
      ├── head
      │    ├── title
      │    └── meta
      └── body
           ├── h1
           ├── p
           └── div
                ├── span
                └── button

Tại sao cần DOM?

  • Thay đổi nội dung trang mà không cần tải lại (SPA, form validation…)
  • Tạo giao diện động: thêm/xóa phần tử, ẩn/hiện, animation
  • Xử lý sự kiện người dùng (click, input, submit…)
  • Là nền tảng của mọi framework frontend (React, Vue, Angular đều dựa trên DOM)

2. Chọn phần tử trong DOM

Trước khi thao tác, bạn phải chọn được phần tử. Có 2 nhóm phương thức chính:

2.1. Các phương thức cổ điển (getElement*)

Phương thức Trả về Live? Ghi chú
getElementById(id) Element | null — Nhanh nhất (O(1)), ID phải unique
getElementsByClassName(class) HTMLCollection Live Cập nhật theo DOM realtime
getElementsByTagName(tag) HTMLCollection Live Theo tên thẻ
getElementsByName(name) NodeList Live Chủ yếu dùng với form

2.2. Phương thức hiện đại (querySelector*)

Phương thức Trả về Live? Ghi chú
querySelector(css) Element | null — Lấy phần tử đầu tiên khớp CSS selector
querySelectorAll(css) NodeList (static) Không Lấy tất cả, có thể dùng forEach
Khuyến nghị hiện nay: Ưu tiên dùng querySelector / querySelectorAll vì linh hoạt với CSS selector. Chỉ dùng getElementById khi chắc chắn cần tốc độ tối đa với ID.

3. Thay đổi nội dung, thuộc tính & style

3.1. Thay đổi nội dung

  • element.textContent – an toàn, chỉ text thuần
  • element.innerHTML – cho phép HTML (cẩn thận XSS)
  • element.innerText – gần giống textContent, tôn trọng CSS ẩn

Demo thay đổi nội dung

Nội dung ban đầu của đoạn văn này.

const el = document.getElementById('content-demo');

// An toàn – chỉ text
el.textContent = 'Nội dung mới an toàn';

// Cho phép HTML
el.innerHTML = '<strong>In đậm</strong> và <em>nghiêng</em>';

3.2. Thay đổi thuộc tính (Attribute)

const img = document.querySelector('img');

// Cách 1: thuộc tính trực tiếp
img.src = 'new-image.jpg';
img.alt = 'Mô tả mới';

// Cách 2: setAttribute / getAttribute
img.setAttribute('src', 'new-image.jpg');
img.getAttribute('src');

// Data attributes
img.dataset.userId = '123';          // data-user-id="123"
console.log(img.dataset.userId);    // "123"

// 2. Tạo text node (ít dùng)
const text = document.createTextNode('Chỉ text thuần');

// 3. Clone phần tử có sẵn
const clone = existingElement.cloneNode(true); // true = deep clone

4.2. Thêm vào DOM

const parent = document.getElementById('list');

// Cách hiện đại (khuyến nghị)
parent.append(newDiv);               // thêm vào cuối
parent.prepend(newDiv);              // thêm vào đầu
parent.before(newDiv);               // thêm trước parent
parent.after(newDiv);                // thêm sau parent

// Cách cổ điển
parent.appendChild(newDiv);
parent.insertBefore(newDiv, referenceNode);

// insertAdjacentHTML – chèn HTML string

4.3. Xóa phần tử

// Cách hiện đại
element.remove();

// Cách cổ điển
parent.removeChild(element);

// Xóa toàn bộ con
parent.innerHTML = '';               // nhanh nhưng nguy hiểm với event
while (parent.firstChild) {
  parent.removeChild(parent.firstChild);

5. Xử lý sự kiện (Event Handling)

DOM cho phép lắng nghe và phản ứng với hành động của người dùng.

5.1. addEventListener (khuyến nghị)

const btn = document.getElementById('myBtn');

// Cách tốt nhất
btn.addEventListener('click', function(event) {
  console.log('Đã click!', event);
});

// Arrow function
btn.addEventListener('click', (e) => {
  e.preventDefault();          // ngăn hành vi mặc định
  e.stopPropagation();         // ngăn nổi bọt
});

// Xóa listener
btn.removeEventListener('click', handlerFunction);

5.2. Các sự kiện phổ biến

Sự kiệnKhi nào xảy ra
clickClick chuột
dblclickDouble click
inputGiá trị input thay đổi (realtime)
changeGiá trị thay đổi và mất focus
submitForm được gửi
keydown / keyupNhấn / nhả phím
mouseover / mouseoutDi chuột vào / ra
DOMContentLoadedHTML đã parse xong (chưa đợi ảnh)

5.3. Event Delegation (rất quan trọng)

Thay vì gắn listener cho từng phần tử con, gắn một listener duy nhất cho phần tử cha. Rất hữu ích khi danh sách thay đổi động. 
// Thay vì gắn cho từng <li>
document.getElementById('todo-list').addEventListener('click', function(e) {
  if (e.target.matches('li')) {
    e.target.classList.toggle('done');
  }
  if (e.target.matches('.delete-btn')) {
    e.target.closest('li').remove();
  }
});

6. Best Practices khi làm việc với DOM

  1. Chờ DOM sẵn sàng 
    document.addEventListener('DOMContentLoaded', () => {
  // code thao tác DOM an toàn ở đây
});
  2. Cache phần tử – đừng query lại nhiều lần 
    // Tốt
const btn = document.getElementById('submit');
btn.addEventListener(...);
btn.disabled = true;

// Xấu
document.getElementById('submit').addEventListener(...);
document.getElementById('submit').disabled = true;
  3. Ưu tiên classList thay vì style trực tiếp khi có thể
  4. Dùng textContent thay vì innerHTML nếu chỉ cần text (tránh XSS)
  5. Event Delegation cho danh sách động
  6. Tránh reflow/repaint không cần thiết – batch thay đổi DOM

7. Bài tập thực hành (10 bài)

Làm lần lượt từ dễ → khó. Mỗi bài có mô tả rõ ràng. Sau khi làm xong, giáo viên có thể mở phần lời giải bằng mật khẩu.

Bài 1: Thay đổi nội dung tiêu đề

Dễ

Yêu cầu: Tạo một trang có tiêu đề <h1 id="title">Xin chào</h1> và một nút. Khi bấm nút, tiêu đề đổi thành "Chào mừng đến với DOM!" và màu chữ thành xanh dương.

Gợi ý: Dùng getElementById, textContent, style.color.

Bài 2: Ẩn / Hiện phần tử

Dễ

Yêu cầu: Có một đoạn văn và nút "Ẩn/Hiện". Mỗi lần bấm nút thì đoạn văn ẩn hoặc hiện xen kẽ.

Gợi ý: Dùng style.display = 'none' hoặc classList.toggle('hidden').

Bài 3: Đếm số lần click

Dễ

Yêu cầu: Có nút và một đoạn hiển thị số. Mỗi lần bấm nút, số tăng lên 1. Có thêm nút "Reset" để đưa về 0.

Bài 4: Thay đổi màu nền theo input

Trung bình

Yêu cầu: Có ô input type="color" và một div. Khi người dùng chọn màu, nền của div thay đổi theo màu đó ngay lập tức.

Gợi ý: Lắng nghe sự kiện input.

Bài 5: Thêm mục vào danh sách

Trung bình

Yêu cầu: Có ô input + nút "Thêm". Khi bấm Thêm (hoặc Enter), lấy giá trị input tạo thành <li> mới và append vào <ul>. Sau khi thêm thì xóa nội dung input.

Nếu input rỗng thì hiện alert cảnh báo.

Bài 6: Xóa từng mục trong danh sách

Trung bình

Yêu cầu: Mở rộng Bài 5. Mỗi <li> có thêm nút "Xóa". Khi bấm nút Xóa thì xóa đúng mục đó.

Gợi ý: Dùng Event Delegation hoặc gắn listener khi tạo phần tử.

Bài 7: Bộ đếm ký tự realtime

Trung bình

Yêu cầu: Có <textarea> và đoạn hiển thị "Số ký tự: 0". Mỗi khi người dùng gõ, số ký tự cập nhật ngay. Giới hạn tối đa 100 ký tự – nếu vượt thì hiện cảnh báo màu đỏ.

Bài 8: Tab chuyển nội dung

Khó

Yêu cầu: Tạo giao diện 3 tab: "Giới thiệu", "Sản phẩm", "Liên hệ". Khi click vào tab nào thì hiện nội dung tương ứng và ẩn nội dung tab khác. Tab đang active có style khác biệt.

Bài 9: Modal (hộp thoại) đơn giản

Khó

Yêu cầu: Có nút "Mở Modal". Khi bấm thì hiện một lớp phủ (overlay) + hộp thoại ở giữa màn hình. Trong modal có nút "Đóng" và cũng có thể đóng bằng cách click vào vùng overlay bên ngoài.

Bài 10: Todo List hoàn chỉnh

Khó

Yêu cầu: Xây dựng một Todo List có các chức năng:

  • Thêm công việc mới
  • Đánh dấu hoàn thành (gạch ngang + đổi màu)
  • Xóa công việc
  • Đếm số công việc còn lại
  • (Nâng cao) Lưu vào localStorage để khi tải lại trang vẫn còn dữ liệu

Lời giải Bài 10 – Todo List hoàn chỉnh

<input id="todoInput" placeholder="Công việc mới...">
<button id="addTodo">Thêm</button>
<p>Còn lại: <span id="remaining">0</span> công việc</p>
<ul id="todoList"></ul>

<script>
const input     = document.getElementById('todoInput');
const list      = document.getElementById('todoList');
const remaining = document.getElementById('remaining');

let todos = JSON.parse(localStorage.getItem('todos') || '[]');

function save() {
  localStorage.setItem('todos', JSON.stringify(todos));
  render();
}

function render() {
  list.innerHTML = '';
  let left = 0;

  todos.forEach((todo, index) => {
    if (!todo.done) left++;
    const li = document.createElement('li');
    li.innerHTML = `
      <span class="${todo.done ? 'done' : ''}">${todo.text}</span>
      <button data-action="toggle" data-index="${index}">✓</button>
      <button data-action="delete" data-index="${index}">Xóa</button>
    `;
    list.appendChild(li);
  });

  remaining.textContent = left;
}

document.getElementById('addTodo').addEventListener('click', () => {
  const text = input.value.trim();
  if (!text) return;
  todos.push({ text, done: false });
  input.value = '';
  save();
});

list.addEventListener('click', (e) => {
  const btn = e.target.closest('button');
  if (!btn) return;
  const index = Number(btn.dataset.index);

  if (btn.dataset.action === 'toggle') {
    todos[index].done = !todos[index].done;
  } else if (btn.dataset.action === 'delete') {
    todos.splice(index, 1);
  }
  save();
});

render(); // khởi tạo
</script>

<style>
.done { text-decoration: line-through; color: #94a3b8; }
</style>

Giải thích chi tiết:

  • Dữ liệu được lưu trong mảng todos và đồng bộ với localStorage.
  • Hàm render() chịu trách nhiệm vẽ lại toàn bộ danh sách từ dữ liệu.
  • Event Delegation giúp xử lý nút ✓ và Xóa dù chúng được tạo động.
  • Đây là mô hình gần với cách các framework hiện đại hoạt động (data → view).
